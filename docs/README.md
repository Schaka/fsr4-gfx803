# Images

`pragmata-fsr4-411-rx480.jpeg` is a photo of the test machine's monitor, taken in August 2026 with
the patched Mesa 26.1 RADV. It shows Pragmata's title screen with OptiScaler 0.9.4 open. The
OptiScaler overlay reports FSR 4.1.1, and the FSR4 watermark in the top left reads
`FSR4-I8 UPSCALE 4.1.1`. That shows the INT8 model running on a GCN4 card.

The frametime in the overlay is from the title screen, not from gameplay. It is not a benchmark.
The benchmarks are in the main `README.md`.
