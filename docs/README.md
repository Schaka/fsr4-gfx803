# Images

`pragmata-fsr4-411-rx580.jpeg` is a photo of the test machine's monitor, taken on 17 September 2026
with an RX 580. It shows Pragmata in game with the OptiScaler 10.0.0 overlay open, running the
`hybrid` DLL. That is the `daniel-h-0/bc250-fsr4-fork` build of FSR 4.1.1, which the overlay lists
as `FSR 4.1.1r10`, with ten model passes handed back to AMD's shaders so the tuned sets can replace
them.

The overlay reports 1280x720 upscaled to 1920x1080 and an upscaler time of 8.90 ms. It names the card
as an RX 480: the RX 580 is the same Polaris 10 chip under the same device ID, and the name comes
from that ID.

The frametime in the overlay is measured with the overlay itself open, which costs a good deal, so it
is not a benchmark. The benchmarks are in the main `README.md`.

The photo's metadata was removed before it was committed, including the location the phone recorded.
